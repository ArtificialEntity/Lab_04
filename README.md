# Домашние задание к работе номер 4
## Условие Задачи
Тренер формирует стартовый состав из трех игроков с номерами A, B и C. Он считает, что это "счастливая" тройка, если сумма номеров игроков делится на три без остатка. Запишите условие для "счастливой" тройки.
## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало
2. Объявить переменные:
- **A** - первый участник.
- **B** - второй участник.
- **C** - третий участник.
3. Составить условие при помощи операторов if и else.
6. Конец.

## 2. Реализация программы
```﻿#include <stdio.h>
#include <locale.h>

int main()
{
	setlocale(LC_ALL, "RUS");

	int A;

	puts("Введите номер первого игрока: ");

	scanf("%d", &A);

	int B;

	puts("Введите номер второго игрока: ");

	scanf("%d", &B);

	int C;

	puts("Введите номер третьего игрока: ");

	scanf("%d", &C);

	if ((A + B + C) % 3 == 0)
	{
		puts("Тройка является счастливой!");
	}
	else
	{
		puts("Тройка не является счастливой!");
	}

	return 0;
}
```
